# 🤖 AI-Digest — дайджест для новичков

Сайт с карточками про нейросети, промпты, Claude Code и первые проекты.
Сделан на Python + Flask.

## Как запустить

1. Установите Flask один раз:
   ```
   pip install -r requirements.txt
   ```
2. Запустите сайт:
   ```
   python app.py
   ```
   (если команда `python` не работает — используйте `py app.py`)
3. Откройте в браузере: http://127.0.0.1:5000

## Что умеет

- Карточки из файла `content.json` (заголовок, описание, ссылка, теги)
- Поиск по заголовкам, описаниям и тегам
- Фильтр по тегам (клик по тегу внутри карточки тоже работает)
- Кнопка «Открыть материал» на каждой карточке
- Адаптивный дизайн: на телефоне и на компьютере

## Как добавить свою карточку

Откройте `content.json`, скопируйте любую карточку и замените текст.
Постарайтесь использовать существующие теги — так фильтр будет аккуратнее.

## Структура проекта

| Файл | Что это |
|---|---|
| `app.py` | Сервер Flask (запускается через `python app.py`) |
| `content.json` | Все карточки сайта |
| `templates/index.html` | Разметка страницы |
| `static/style.css` | Стили (тёмная тема, анимации) |
| `static/script.js` | Поиск, фильтры, появление карточек |
